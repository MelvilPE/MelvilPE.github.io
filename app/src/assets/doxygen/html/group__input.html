Detailed Description

Input system is a part of the engine which is responsible for:

  • Managing input devices (keyboards, mouses, gamepads etc.)
  • Handling input events sent by a platform
  • Storing each input device's state

Enumeration Type Documentation

§ eInputBindingListenerModes

enum DAVA::eInputBindingListenerModes
strong

Describes input listening modes.

Enumerator
DIGITAL_SINGLE_WITHOUT_MODIFIERS 

Listen for a single element which is not a keyboard modifier.

Examples: W, left mouse button, etc.

DIGITAL_SINGLE_WITH_MODIFIERS 

Listen for a single element which is not a keyboard modifier with possible modifiers.

Examples: W, Shift + W, Ctrl + right mouse button, etc.

DIGITAL_MULTIPLE_ANY 

Listen for sequence of any multiple digital elements.

ANALOG 

Listen for a single analog element input.

Examples: mouse move, gamepad's stick.

§ eInputElements

enum DAVA::eInputElements : uint32

List of all supported input elements.

An input element is a part of a device which can be used for input. For example, a keyboard button, a mouse button, a mouse wheel, gamepad's stick etc. Number values used in this enum are safe to be saved in order to be restored later (e.g. in a config file).

These values can be tested for different properties using functions defined below (i.e. what device type it belongs to, is it a button or not, etc.).

Enumerator
NONE 

Special value used in some cases to specify that no mouse button is involved.

NONE 

No modifier keys are pressed.
