DAVA::EntityCache Class Reference
3D Engine

Detailed Description

This class is a code of our 3D Engine scene graph.

To visualize any 3d scene you'll need to create Scene object. Scene have visible hierarchy and invisible root nodes. You can add as many root nodes as you want, and do not visualize them. For example you can have multiple scenes, load them to one scene, and show each scene when it will be required.
