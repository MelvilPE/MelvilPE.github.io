DAVA::AutoResetEvent Class Referencefinal

Detailed Description

AutoResetEvent Notifies a waiting thread that an event has occurred.

A thread waits for a signal by calling Wait() on the AutoResetEvent. If the AutoResetEvent is in the non-signaled state, the thread blocks, waiting for the thread that currently controls the resource to signal that the resource is available by calling Signal().

Calling Signal() signals AutoResetEvent to release a waiting thread. AutoResetEvent remains signaled until a single waiting thread is released, and then automatically returns to the non-signaled state. If no threads are waiting, the state remains signaled indefinitely.
