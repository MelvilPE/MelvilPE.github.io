Detailed Description

RichContent compoent support tag aliases.

Any alias contains alias name, original tag and original attributes. After declaration of alias you can use it like an any tag in the content source. But all attributes witch will be added to alias in content source will be ignored and replaced by attributes from alias data.

For example: Defined aliases: h1 =

In this case tag h1 with its attributes will be raplaced by tag p with attributes class="header".
