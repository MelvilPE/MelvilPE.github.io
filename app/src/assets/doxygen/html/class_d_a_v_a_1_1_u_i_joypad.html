§ eControlState

enum DAVA::UIControl::eControlState
inherited
Enumerator
STATE_NORMAL 

Control isn't under influence of any activities.

STATE_PRESSED_OUTSIDE 

Mouse or touch comes into control but dragged outside of control.

STATE_PRESSED_INSIDE 

Mouse or touch comes into control.

STATE_DISABLED 

Control is disabled (don't process any input). Use this state only if you want change graphical representation of the control. Don't use this state for the disabling inputs for parts of the controls hierarchy!.

STATE_SELECTED 

Just a state for base control, nothing more.

STATE_HOVER 

This bit is rise then mouse is over the control.

STATE_FOCUSED 

Control under focus and will receive keyboard input. Additional this state can be used for setting visual style of control.

§ eEventType

enum DAVA::UIControl::eEventType
inherited
Enumerator
EVENT_TOUCH_DOWN 

Trigger when mouse button or touch comes down inside the control.

EVENT_TOUCH_UP_INSIDE 

Trigger when mouse pressure or touch processed by the control is released.

EVENT_VALUE_CHANGED 

Used with sliders, spinners and switches. Trigger when value of the control is changed. Non-NULL callerData means that value is changed from code, not from UI.

EVENT_FOCUS_SET 

Trigger when control becomes focused.

EVENT_FOCUS_LOST 

Trigger when control lost focus.

EVENT_TOUCH_UP_OUTSIDE 

Trigger when mouse pressure or touch processed by the control is released outside of the control.
