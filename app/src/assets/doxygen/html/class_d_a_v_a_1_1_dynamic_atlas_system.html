DAVA::DynamicAtlasSystem Class Referencefinal

Detailed Description

System for baking many sprites into large texture atlases at runtime.

Supports only images with uncompressed format (RGB888, RGBA8888). Adds one pixel margin between regions to avoid artifacts. Automatically dispose atlas textures when all related sprites deleted. Call "Sprites::Reload()" removes sprite from atlas and load defaults.

Attention!!! You must not render 'isDynamicAtals' sprites loaded between 'BeginAtlas' and 'EndAtlas' calls, because textures will be null. Not recommended to using for sprites with shared textures.
