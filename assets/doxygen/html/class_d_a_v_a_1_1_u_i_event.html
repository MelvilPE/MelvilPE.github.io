Enumerator
INPUT_NOT_HANDLED 

Input is not handled at all.

INPUT_HANDLED_SOFT 

Input is handled, but input control can be changed by GetEngineContext()->uiControlSystem->SwitchInputToControl() method.

INPUT_HANDLED_HARD 

Input is handled completely, input control can't be changed.
