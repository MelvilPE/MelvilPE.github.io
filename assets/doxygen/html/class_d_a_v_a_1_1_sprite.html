DAVA::Sprite Class Referenceabstract

Detailed Description

Main class to draw 2d objects on screen.

This object is fast and efficient for drawing 2d objects on screen. It supports texture-atlassing and it uses texture atlasses automatically. You can set scale, rotate, pivot point, angle and position for any sprite object before rendering.
