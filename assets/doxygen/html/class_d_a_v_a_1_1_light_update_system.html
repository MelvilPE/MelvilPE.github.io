DAVA::LightUpdateSystem::LightUpdateSystem ( Scene *  scene)

Constructor for the LightUpdateSystem class.

The LightUpdateSystem is responsible for managing and updating lighting within a 3D scene. It handles the processing of light sources, shadows, and related lighting calculations.

Parameters
scenePointer to the Scene object this system will operate on
