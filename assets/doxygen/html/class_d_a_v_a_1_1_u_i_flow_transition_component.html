Detailed Description

Component configures possible transitions rules from current state to another states by specified events.

Each rule contains event name, which should be processed by this rule, type of processing and processing argument depends by selected type.

Available types are: Activate (argument is path to state which should been activate), Deactivate (argument is path to state with should been deactivate), ActivateBackground (same as Activate but loading step will be executed in other thread), DeactivateBackground (same as Deactivate but unloading step will be executed in other thread), SendEvent (argument is new event which should been fire), HistoryBack (without arguments).
