Load item with path path, attach it into entity rootEntity and call finishCallback.

Loading can be processed in worker thread, but finishCallback should be called from 'Process' method. If argument of finishCallback is empty, slot system think that loading was successful, else slot system set state for slot as LOADING_FAILED and print argument into Logger::Error
