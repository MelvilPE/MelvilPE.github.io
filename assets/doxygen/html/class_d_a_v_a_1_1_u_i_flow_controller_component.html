DAVA::UIFlowControllerComponent Class Referencefinalabstract

Detailed Description

Component attaches controller (native or lua) to the state.

Native controller should be inherited from UIFlowController. Lua script can contains next functions: init(context), activate(context, view), loadResources(context, view), process(frameDelta), processEvent(eventName) (must return true for avoid sending current event next), deactivate(context, view), unloadResources(context, view), release(context).
