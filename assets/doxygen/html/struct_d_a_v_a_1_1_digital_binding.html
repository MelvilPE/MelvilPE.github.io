§ outputAnalogState

AnalogElementState DAVA::DigitalBinding::outputAnalogState

Analog state which will be put into a triggered action.

Useful in cases when a button performs the same action as an analog element. For example if a user uses gamepad's stick for MOVE action (which sends [-1; 1] values for x and y axes), he might also want to bind movement to WASD buttons. In this situation, he can specify (0, 1) for W, (-1, 0) for A, (0, -1) for S and (0, 1) for D, thus unifiying input handling code for this action:

if (action.actionId == MOVE)
{
// Don't care about the way analogState was filled
// Just know that it's in a range [-1; 1] for x and y
Vector2 velocity(action.analogState.x, action.analogState.y);
Move(velocity);
}
