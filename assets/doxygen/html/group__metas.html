§ Bindable

using DAVA::M::Bindable = typedef Meta<Metas::Bindable>

Indicates that we can bind UIControl/UIComponent reflection field to some data from model.

QuickEd uses this indication to build special editor in Property Panel.

§ Enum

using DAVA::M::Enum = typedef Meta<Metas::Enum>

Add hint that indicates that value of Reflected Field is enum and value has String representation The following sample shows how to specify Enum meta for field:

enum ErrorCode
{
NoErrors,
OutOfBound,
InvalidArgument
}
DAVA_REFLECTION(Error)
{
ReflectionRegistrator<Error>::Begin()
.Field("error", &Error::error)[M::EnumT<ErrorCode>()]
.End()
}

To get Enum meta from field you shoul use M::Enum:

Reflection ref = model.GetField("error");
const M::Enum* enumMeta = ref.GetMeta<M::Enum>();
if (enumMeta != nullptr)
{
const EnumMap* enumMap = enumMeta->GetEnumMap();
// some client code here
}

§ Range

using DAVA::M::Range = typedef Meta<Metas::Range>

Add hint that indicates valid range of value.

  • minValue has value of DAVA::Any
  • maxValue has value of DAVA::Any Control will try to cast minValue and maxValue to control specific type T If some of bound couldn't be casted to T, this bound will be equal std::numeric_limits<T>::min.

§ SubProperty

using DAVA::M::SubProperty = typedef Meta<Metas::SubProperty>

We think about some types like about base types: Vector2, Vector3, Vector4, Color, Rect etc But in real this types are complex and have fields.

For example Vector3 comprises the following fields: X, Y, Z This meta mark field of "BaseType" as "field to edit". As a reaction there will be created separate sub-editor for each field that marked by this meta

§ ValueDescription

using DAVA::M::ValueDescription = typedef Meta<Metas::ValueDescription>

Specify function that can provide string representation of value.

  • descriptionFunction has value of String (*)(const DAVA::Any& value)

Example:

void VisibleFieldDescription(const Any& value)
{
return value.Cast<bool>() == true ? String("Visible") : String("Invisible");
}
DAVA_REFLECTION(Entity)
{
ReflectionRegistrator<Entity>::Begin()
.Field("Visible", &Entity::visible)[M::ValueDescription(&VisibleFieldDescription)]
.End();
}
