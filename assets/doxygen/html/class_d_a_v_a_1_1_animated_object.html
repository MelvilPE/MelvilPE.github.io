Animation System

Detailed Description

AnimatedObject is base class for objects that need to be animated.

For example UIControl, GameObject and so on. All objects inside the system that has to be animated must be derived from this class. You cannot use the AnimatedObject class directly. It instead defines the common interface and behavioral structure for all its subclasses.
