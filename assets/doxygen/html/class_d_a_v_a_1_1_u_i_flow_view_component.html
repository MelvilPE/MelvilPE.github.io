DAVA::UIFlowViewComponent Class Referencefinalabstract

Detailed Description

Component configures view representation of state.

It contains path to yaml with content, control name which will be loaded from yaml and path to control-container on parent view where the loaded view will be added.

Also this component configures data-binding data source by the name which was stored in context.data and data scope expression.
