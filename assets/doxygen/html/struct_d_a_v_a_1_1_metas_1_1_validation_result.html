enum DAVA::Metas::ValidationResult::eState
strong

This enum type defines the state in which a validated value can exist.

Enumerator
Invalid 

Inputted value isn't valid and should be discarded.

Intermediate 

Inputted value can be valid.

For example value 4 invalid for Range(10, 99) but we should allow user continue editing because value 40 is valid

Valid 

Inputted value is completely valid.
