DAVA::Any Class Referencefinal

Detailed Description

The class Any is a type-safe container for single value of any type.

Stored value is always copied into internal storage. Implementations is encouraged to avoid dynamic allocations for small objects, but such an optimization may only be applied to types for which std::is_nothrow_move_constructible returns true.

Remarks
This class cannot be inherited.

Any can be copied.

  • Internal storage with trivial value will also be copied.
  • Internal storage with complex type will be shared the same way as std::shared_ptr do.

Typical usage:

void foo()
{
int i = 1;
const char* s = "Hello world";
Any a;
a.Set(i);
std::count << a.Get<int>(); // prints "1"
a.Set(s);
std::count << a.Get<const char*>(); // prints "Hello world"
}

§ operator==()

bool DAVA::Any::operator== ( const Any &  any) const

Equality operator.

Two Any objects can be equal only if they both contain values of the same Any::type. Values of type for which Type::IsTrivial is true are compared by ::std::memcmp function. Values with other types can be compared only if AnyCompate class has specialization for thous type.

Exceptions
DAVA::Exceptionthere is no appropriate compare operation for contaited values.
