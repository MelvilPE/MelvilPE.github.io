Detailed Description

template<typename T>
class DAVA::Dispatcher< T >

Template class that implements event dispatcher where template parameter T specifies event type.

T must be copy or move constructible.

Dispatcher manages event queue and provides methods to place events to queue and extract events from queue. Application can place events from any thread, but extraction must be performed only from single thread which should stay the same until dispatcher dies. Event extraction thread is set by LinkToCurrentThread method.
