All architecture approaches & patterns we've selected in our framework is well-known and described.

Helper to implement event dispatchers.

In some cases we want to avoid inheritance from multiple objects. But some classes require to be both singletons & handle events. For these cases we've added this define to avoid multiple copying of the same code.

void DAVA::SafeRelease ( C *&  c)

function to perform release safely.

It checks if given object not equal to zero, in debug mode it also checks if such object haven't deallocated before and only if both checks is positive it call Release. After release it set value of variable to 0 to avoid possible errors with usage of this variable
