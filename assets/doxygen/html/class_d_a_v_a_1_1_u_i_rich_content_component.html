DAVA::UIRichContentComponent Class Referenceabstract

Detailed Description

Describe rich content inside control.

Format of input text source it xml (or xhtml).

For default all text content in any tags will be added as UIStaticText controls. Also all tags support attribute class witch set specified class to created UIStaticText controls.

Special rules available for next tags:

- paragraph. Text content inside this tag will be wrap by new lines.

    - unordered list and list item. Text content inside these tags will be wrap by new lines and before all lines in li tag will be added bullet symbol.
  • - image. Insert UIControl with UIControlBackground component and set intro it sprite by path specified in src attribute.
  • <object path="..." control="..." prototype="..." name="..."> - custom control. Insert clone of specified control by root control name or prototype name witch contain in package by specialized path. Also set name to this clone from name attribute. Attribute path and one of attributes control or prototype are required. Attribute name is optional.
